Project: A tool that tests how fast a small PyTorch model runs on CPU or GPUs,
makes failures on purpose, and explains what went wrong.

Rules:
- I use a Mac with no NVIDIA GPU, so everything must run on CPU first.
- If a GPU is available, use it automatically.
- Keep the code simple, with comments.
- Use a tiny model and fake data.
- Never invent results. All numbers must come from real runs.
- Work one step at a time and tell me how to test each step.
